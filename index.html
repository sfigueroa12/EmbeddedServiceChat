Antes de probar

  1. En Salesforce, añade tu URL de GitHub Pages a CORS y a los dominios permitidos del Embedded Service Deployment. Ejemplo: https://tu-usuario.github.io
  2. Republica el deployment si cambias dominios.
  3. Genera un JWT con el mismo kid e iss del Keyset. El sub debe ser un ID estable de prueba.
  4. Pega el JWT arriba. El botón de chat aparece tras setIdentityToken.
